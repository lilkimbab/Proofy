# AI 학습 코치 UI 기획 요약

## 한 줄 목적

사용자가 올린 학습 자료를 바탕으로 문제를 만들고, 답안을 채점한 뒤, 오답을 줄일 수 있도록 다음 학습 행동까지 안내하는 AI 학습 코치.

## 서비스가 해결하는 문제

- 자료는 많은데 무엇을 공부해야 할지 정리하기 어렵다.
- 시험 대비 문제를 직접 만들기 어렵다.
- 혼자 풀고 나면 왜 틀렸는지 정확히 알기 어렵다.
- 오답 이후에 무엇을 복습해야 할지 흐름이 끊긴다.

## 핵심 사용자 흐름

1. 자료 업로드
2. 핵심 개념 확인
3. 문제 생성
4. 문제 풀이
5. 채점과 피드백 확인
6. 오답 맞춤 연습
7. 약점 개념 복습

## 주요 화면

### 1. 홈 화면

- 최근 학습 자료
- 오늘 풀 문제
- 오답 복습 바로가기
- 시험 대비 모드 시작

### 2. 자료 화면

- 업로드한 PDF/필기/텍스트 목록
- 자료별 핵심 개념
- 자료 기반 질문하기
- 문제 만들기 버튼

### 3. 문제 생성 화면

- 자료 선택
- 문제 유형 선택
  - 객관식
  - 주관식
  - OX
  - 빈칸
  - 개념 카드
- 난이도 선택
  - 쉬움
  - 보통
  - 어려움
- 목적 선택
  - 개념 확인
  - 시험 대비
  - 오답 복습

### 4. 문제 풀이 화면

- 문제 본문
- 보기 또는 답안 입력창
- 풀이 과정 입력
- 제출 버튼
- 제출 전에는 정답과 해설을 보여주지 않음

### 5. 피드백 화면

- 맞았는지 여부
- 헷갈린 지점
- 올바른 개념 설명
- 자료 근거
- 다음 행동 버튼
  - 힌트만 보고 다시 풀기
  - 비슷한 문제 풀기
  - 개념 카드로 복습
  - 풀이 흐름 보기

### 6. 오답노트 화면

- 자주 틀린 개념
- 오답 유형
- 다시 풀 문제
- 복습이 필요한 자료 위치

### 7. 시험 대비 화면

- 선택한 자료 범위
- 예상 문제 세트
- 미니 모의고사
- 주관식 채점
- 약점 요약

## 제품의 차별점

- 단순 요약이 아니라 실제로 풀 수 있는 문제를 만든다.
- 사용자가 푼 답안을 채점한다.
- 왜 틀렸는지 구체적으로 알려준다.
- 오답을 바탕으로 다음 문제를 다시 만든다.
- 모든 문제와 피드백은 사용자가 올린 자료를 근거로 한다.

## 화면 문체

기본 말투는 친근한 존댓말을 사용한다.

좋은 예:

- 맞았어요. 핵심 조건을 잘 잡으셨어요.
- 여기서 헷갈린 건 원인과 결과의 순서예요.
- 자료에서는 이 부분을 이렇게 설명하고 있어요.
- 비슷한 문제로 한 번만 더 확인해볼까요?

피할 표현:

- 오답입니다.
- 이해도가 부족합니다.
- 분석 결과입니다.
- 학습을 진행하세요.

## UI에서 가장 중요하게 보여줄 것

- 지금 무엇을 풀고 있는지
- 어떤 자료를 근거로 만든 문제인지
- 왜 맞았거나 틀렸는지
- 다음에 무엇을 하면 되는지
